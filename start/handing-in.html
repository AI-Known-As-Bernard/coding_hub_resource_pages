Before you submit

Most lost marks are process, not code.

01 Name files the way the assignment says

Names are how I find your work among thirty others. A file called Untitled-1.html or final FINAL v2.html costs you time and me patience.

Three rules that apply to every file you hand in:

naming
RuleYesNo
Lowercase onlyportfolio.htmlPortfolio.HTML
Hyphens, never spacesplant-tracker.jsplant tracker.js
No version numbers in the nameindex.htmlindex-final-v3.html

02 The entry file is always index.html

A web project opens at index.html. That is a rule of the web, not a preference of mine: a browser pointed at a folder looks for that exact name.

If your main page is called home.html or Portfolio.html, the link I open shows a file listing or a 404, and your project reads as broken before I have seen a line of it.

a project folder ready to hand in
plant-tracker/
|- index.html          <- the entry point, this exact name
|- css/
|   +- styles.css
|- js/
|   +- app.js
|- images/
|   +- fern.jpg
+- README.md           <- what it is and how to run it

03 Check your links before you submit

Links that work on your machine often break for everyone else, and there are only two causes. Both are easy to check.

Capitalisation. Windows and Mac treat Fern.jpg and fern.jpg as the same file. The web server does not. A capital letter in the wrong place is the single most common reason images vanish once work is handed in.

paths
src="images/fern.jpg"        <- relative. Travels with the folder.
src="/images/fern.jpg"       <- starts at the site root. Often breaks.
src="C:/Users/you/fern.jpg"  <- your hard drive. Never works for anyone else.

href="../index.html"         <- up one folder, then index.html

05 Zipping a folder

Zip the folder itself, not the files inside it. Selecting the contents and zipping those produces an archive that explodes loose files over whoever opens it.

Open your own zip before you submit it. You should see one folder, and that folder should contain index.html.

how
SystemSteps
WindowsRight-click the folder > Send to > Compressed (zipped) folder
MacRight-click the folder > Compress
Terminalzip -r plant-tracker.zip plant-tracker

06 Never include node_modules

If your project uses npm, the node_modules folder holds tens of thousands of files that are not yours and that anyone can rebuild with one command.

Zipping it turns a 40 KB submission into a 200 MB one. Add a .gitignore before your first commit and the problem never comes up.

.gitignore
node_modules/
.env
.DS_Store
*.log

07 What counts as late, and resubmitting

[Replace this section with your own late and resubmission policy.]

Whatever the policy says, two things are always true. A submission is timestamped when it uploads, not when you finished working — leave a margin. And a file that will not open counts as not submitted, which is why the checklist below exists.

Something went wrong and you cannot submit? Tell me before the deadline, not after. A message beforehand is a conversation; the same message afterwards is an excuse.
