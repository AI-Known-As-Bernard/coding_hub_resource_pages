Writing code

Words about the code itself.

01 The basics

The words that turn up in the first fortnight and then never stop.

A to I
argument
A value you pass into a function when you call it. The name in the definition is the parameter. greet("Ada")
boolean
A value that is either true or false. Named after George Boole.
comment
A note for humans that the language ignores. # like this
concatenate
Join two strings end to end. "ab" + "cd"
condition
An expression that is true or false, used to decide what runs next.
expression
Anything that produces a value. 2 + 2 is an expression; x = 4 is a statement.
function
A named block of code you can run on demand.
index
A position in a list or string. Counting starts at zero.
iterate
Go through a collection one item at a time. What a loop does.

02 More terms

The second half of the alphabet, same idea.

L to Z
literal
A value written directly in the code. 42, "hello", True
method
A function that belongs to a value, called with a dot. name.upper()
mutable
Able to be changed in place. Lists are mutable; strings are not.
parameter
The name in a function definition that receives an argument.
return
Hand a value back from a function to whatever called it. Not the same as printing it.
scope
Where a name exists. A variable made inside a function usually does not exist outside it.
statement
One instruction. Usually one line.
string
Text. Always in quotes.
syntax
The grammar of a language — where the colons and brackets go.
variable
A name pointing at a value.
whitespace
Spaces, tabs and newlines. Python uses them to mark blocks, so they matter.

Running code

Words about what happens when you press go.

03 Running and breaking

Most of these turn up in error messages, which is usually where you meet them first.

terms
bug
A mistake in the code. From an actual moth found in a computer in 1947.
compile
Translate source code into something a machine runs, before running it. Python and JavaScript do not need this step.
debug
Find and fix a bug. The skill, not the accident.
exception
An error raised while the program runs, which stops it unless you catch it.
execute
Run.
interpreter
The program that reads your source and runs it. python is one.
runtime
While the program is running — as opposed to when you are writing it.
stack trace, traceback
The list of calls that led to an error. Read it bottom-up.
syntax error
Code the language cannot read at all. Nothing runs.

The web

Words about pages and servers.

04 Front end

Everything that happens in the browser.

terms
attribute
Extra information on an HTML tag. href="/shop"
class
A label on an HTML element so CSS and JavaScript can find it. Different from a class in object-oriented programming.
CSS
Cascading Style Sheets. Decides how the page looks.
DOM
Document Object Model. The live tree of objects the browser builds from your HTML, and what JavaScript changes.
element
One thing in an HTML document: a paragraph, an image, a button.
event
Something that happens in the page — a click, a keystroke — that your code can respond to.
HTML
HyperText Markup Language. The structure and meaning of a page.
responsive
A layout that works at any screen width.
selector
A pattern that picks out elements. .card h2
tag
The marker around an element. &lt;p&gt; ... &lt;/p&gt;

05 Back end

Everything that happens on the server, and the words for how the two halves talk.

terms
API
Application Programming Interface. A set of URLs another program can call to get or change data.
backend
The part that runs on a server: the database, the API, the logic users never see.
database
Organised storage that survives restarts.
endpoint
One URL of an API, with a method. GET /api/v1/plants
JSON
A text format for structured data. The way APIs almost always send it.
middleware
A step every request passes through before reaching its handler.
request / response
A client asks, a server answers. The whole of HTTP.
route
A method and path mapped to the code that handles it.
server
A program that waits for requests and answers them. Also the computer it runs on.
status code
A number saying how a request went. 200 fine, 404 not found, 500 server broke.

Tools

Words about the things around the code.

06 Editor, terminal, Git

Words about the tools rather than the code.

terms
branch
A separate line of commits in Git, so you can work without disturbing main.
commit
One saved snapshot in Git, with a message.
dependency
A package your project needs in order to run.
directory
A folder. The terminal's word for it.
environment variable
A setting passed to a program from outside it. Where secrets live.
IDE
Integrated Development Environment — an editor with extras. VS Code is close enough to one.
package
Someone else's code you install and use.
path
Where a file is. css/styles.css
repository, repo
A folder Git is tracking.
terminal, shell, command line
Three names for typing commands at your computer.
version control
Keeping a history of changes so you can go back. Git is one.
