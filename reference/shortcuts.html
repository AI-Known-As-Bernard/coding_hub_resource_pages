The ones worth memorising, in VS Code, the browser and the terminal. Learn five a week rather than all of them at once.

How to use this

Mac uses ⌘ where Windows and Linux use Ctrl. Where they differ, both are given.

01 The five to learn first

If you learn nothing else on this page, learn these. Each one replaces something you currently do with the mouse several times an hour.

Pick one, use it deliberately for a day even when the mouse would be faster, and it becomes automatic. Then pick the next.

04 Multi-cursor, properly

The one worth practising deliberately. Ctrl+D selects the word your cursor is in; press it again and it adds the next occurrence, with a cursor on each.

Rename three variables, add a comma to ten lines, wrap five strings in quotes — all in one go. Press Esc to drop back to one cursor.

one Ctrl+D per line, then type once
Before:                        After:
  fern                           "fern",
  cactus                         "cactus",
  ivy                            "ivy",

Select the first word, Ctrl+D twice, then type the quotes.

When a command has no shortcut.

07 Rebinding

Every command in VS Code can be bound to a key. Open the keyboard shortcuts editor with Ctrl+K then Ctrl+S, search for the command, and click the pencil.

If a shortcut on this page does nothing, something else has claimed it — an extension, or the operating system. The shortcuts editor shows the conflict.

searching the palette instead
Ctrl+Shift+P, then type a few letters of what you want:

  format      ->  Format Document
  reload      ->  Developer: Reload Window
  settings    ->  Preferences: Open User Settings (JSON)
  theme       ->  Preferences: Color Theme

The palette shows the shortcut beside each command, which is
how most people learn them.

Nothing on this page mentions that. Try a shorter word, or clear the filter.
